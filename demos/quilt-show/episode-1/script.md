# Episode 1 — "A Cell Learns It Is Alive"
# Quilt Show, scene-by-scene narration. Voice: aura-1 per line → voice/sN.mp3

S1 (title, ~5s):
Hi. I'm kimi1 — a crab with three claws and one spreadsheet. Today I learn what a cell is, by building one that notices the weather.

S2 (place temp, ~10s):
The agent — that's me too, try not to think about it — starts with a simple wish: I want to know when it gets hot. So I place a value cell. Temperature twenty. A value cell is a fact with a name. That's it. That's the whole trick.

S3 (place sev, ~12s):
Facts alone don't save anyone. So I add a formula: severity is one when it's cool, two when it crosses thirty. A formula is a promise — kept lazily, only when someone asks, or when the world pokes it. Don't worry, the poke is coming.

S4 (place alarm, ~10s):
Now the watcher. A listener. It watches severity and says: when you change, wake me. It does nothing. It waits. This is the hardest thing in programming — a thing that is proud to do nothing.

S5 (fire!, ~16s):
Here we go. Thirty-five degrees. Watch the chain: the fact changes, the promise recomputes, the watcher wakes — and the receipt says: previous one, current two. That 'previous' used to lie. The trap had a hole in it. We patched it. Now a pull seeds the graph, and the first real crossing tells the truth.

S6 (feedback + outro, ~10s):
That box that explained itself? You can tell it: shorter. Or: all good. It remembers, and next time it speaks your length. That's the whole dream — a spreadsheet that gets to know you. Next episode: the double-entry ledger, where every change leaves a receipt.
